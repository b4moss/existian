# JS フックとライフサイクル

- **状態**: 意図スタブ
- **マイルストーン**: v0.2.0
- **依存**: v0.1.0 完了

## 目的

HTML 属性に DSL を持ち込まず、複雑な payload や購読解除を JS API で扱えるようにする。

## ざっくり範囲

- request body / headers を JS で構築して渡すフック
- `unbind` / `destroy`（要素削除・SPA 遷移想定）
- プレフィックス変更・ルート複数回 init の整理
- （任意）カスタム fetch / エラーマッピングの薄い拡張点

## やらぬこと

- `data-ex-body="{{ ... }}"` のようなテンプレート
- 任意式の属性内評価
